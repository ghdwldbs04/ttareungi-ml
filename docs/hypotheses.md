# 최종 가설 및 판단 기준 (v1, 2026-11-15)

## 연구 질문
**서울 따릉이의 성공 요인은 다른 도시에서도 통할까? 통하지 않는다면 어떤 조건에서 통하지 않을까?**

이 프로젝트는 이용량 예측 자체가 목적이 아니라, 서울에서 학습한 모델과 요인이 다른 도시로 **전이(transfer)되는지** 검증하는 것이 목적이다.

> 해석 원칙: 모든 분석은 연관 관계를 다룬다. "이용량을 결정한다"가 아니라 "이용량을 설명하는 데 기여한다"로 표현한다.

## 3. 가설과 판단 기준

### H1. 서울에서 입지 요인은 대여소 이용량을 설명하는 데 기여한다
- **분석:** 서울 내 변수별 Spearman 상관 (BH 보정)
- **모델:** 서울 내부 공간 블록 CV, 그룹 단위 Permutation Importance, SHAP
- **판단:** 공간 CV 순위 상관이 인구 단독 기준선보다 높고, 상위 요인 그룹의 상관 방향과 SHAP 방향이 일치하면 지지

### H2. 서울 모델은 다른 도시 안에서 대여소 간 상대적 순위를 예측한다
- **분석:** 변수별 상관 방향이 서울과 같은지 (부호 일치율)
- **모델:** 서울 학습 → 대전·세종·창원 예측, Spearman
- **기준선:** 격자 인구(`grid_pop_total`) 순위만으로 줄 세우기
- **판단:** 대상 도시에서 서울 모델 Spearman이 기준선보다 높고, 부트스트랩 95% 신뢰구간이 0을 포함하지 않으면 지지

### H3. 절대 이용량 수준은 도시마다 달라 서울 모델을 그대로 적용하면 맞지 않는다
- **지표:** MAE, RMSE, Bias(예측 − 실제), 예측/실제 평균 비율 (원래 단위와 로그 변환 단위 모두)
- **평균 보정 실험 (데이터 누수 구분)** — 보정은 원래 단위 평균을 맞추는 배율 방식(k = Σ실제 / Σ예측). 로그 변환 단위에서 평균을 이동하면 원래 단위에서 과보정되기 때문
  - **Oracle 보정 (진단용):** 테스트 도시 전체의 실제 평균으로 편향 보정. 구조적 오차와 도시 수준 편향을 분리하기 위한 진단이며, 실제 적용 성능으로 해석하지 않는다.
  - **Calibration 보정 (적용 가능성):** 대상 도시 대여소 일부(예: 10%)로만 편향을 추정하고 나머지에서 평가. 무작위 분할 반복으로 평균과 분산을 보고한다.
- **판단:** 보정 전 예측/실제 비율이 0.8~1.25 밖이고, 보정 후 MAE가 뚜렷하게 감소하면 "순위는 맞고 수준만 다르다"로 지지
- **해석 주의:** 도시 수준 차이는 데이터에 없는 요인(요금, 운영 방식, 자전거 수, 시스템 역사 등)일 수 있으므로 "입지 피처로 설명되지 않는 도시 수준 차이"로 표현

### H4. 요인마다 전이 가능성이 다르다
- **분석:** 도시별 변수 분포와 변동성, 서울 범위와 겹치는 비율, 변수×도시 상호작용 회귀 (HC3 강건 표준오차)
- **모델:** 서울 모델을 각 도시에 적용해 **같은 기준**으로 SHAP 계산 (배경 데이터 = 서울 학습 데이터), 그룹 단위 Permutation Importance
- **판단 (요인 × 도시마다 분류)**

| 분류 | 조건 |
|---|---|
| 식별 불가 | 해당 도시에서 대표 변수 최빈값 비율 ≥ 95% (도시 내 변동성 부족으로 효과 추정 불가) |
| 범위 밖 | 해당 도시 대여소 중 서울 5~95% 범위 안에 있는 비율 < 50% (외삽) |
| 전이됨 | 도시별 기울기가 서울과 같은 부호이고 상호작용 p ≥ 0.05 |
| 크기 차이 | 같은 부호이나 상호작용 p < 0.05 |
| 방향 불일치 | 부호가 반대이고 상호작용 p < 0.05 |

> "전이됨"은 서울과의 차이가 통계적으로 검출되지 않았다는 뜻이다. 표본이 작은 도시(창원 341곳)는 검정력이 낮으므로 신뢰구간 폭을 함께 보고하고, "같다"고 단정하지 않는다.
>
> 예: 세종·창원은 1km 내 지하철역 수가 모두 0 → 지하철 요인은 "전이 실패"가 아니라 "도시 내 변동성 부족으로 효과 식별 불가". 지하철 요인 전이는 서울 vs 대전에서만 검증 가능. 세종 BRT 데이터는 없음 (한계).

### H5. 여러 도시를 섞어 학습하면 서울 단독 학습과 전이 성능이 달라진다
- **실험:** ① 서울 단독 학습, ② 대상 도시를 뺀 나머지 전체로 학습, ③ ②에서 서울 표본 수(2,765)에 맞춰 무작위 추출해 학습 (10회 반복)
- **비교:** 대전·세종·창원 세 도시에서만 (서울 단독은 서울을 평가할 수 없음)
- **해석:** ③ vs ①은 도시 다양성 효과, ② vs ③은 데이터 양 효과
- **판단:** 방향을 미리 정하지 않고 최종 결과로 판단

## 4. 검증 설계 공통 사항
- **공간 CV:** 블록 크기 3km 기본, 1km·5km 민감도 분석
- **모델:** Ridge, RandomForest, HistGradientBoosting, LightGBM (설치 시)
- **재현성:** random_state = 42 고정

## 6. 한계 및 확인 사항
- 신규 후보지 예측은 기존 대여소 위치로 학습한 모델을 미설치 지역에 적용하는 것이므로, 기존 대여소의 입지 선택 편향과 학습 범위 밖 예측 문제가 있다. 후보지 격자 피처는 전처리 담당과 확보 여부 협의 필요.
- 대여소 밀도(`stations_500`), 운영 요인은 현재 입력에서 제외 (보류 피처).
